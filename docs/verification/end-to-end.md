# End-to-end verification

- [ ] React application loads.
- [ ] Cognito login and logout complete.
- [ ] A request with a valid JWT reaches the API.
- [ ] A request without a valid JWT is rejected in the AWS profile.
- [ ] A task can be created and listed.
- [ ] A task cannot be read or modified by another user.
- [ ] The ALB Target Group reports all expected targets as Healthy.
- [ ] The RDS endpoint is reachable from the application subnets.
- [ ] Terraform state and the AWS console show the intended resources.
