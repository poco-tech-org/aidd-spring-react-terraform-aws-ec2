# Udemy submission checklist

- [ ] Every lecture has a clear objective and completion condition.
- [ ] The screencast cursor and narration stay synchronized.
- [ ] Technical terms have been checked for pronunciation in the ElevenLabs audio.
- [ ] The course description contains the required AI-use disclosure.
- [ ] Code, Terraform, screenshots, and commands match the final recording.
- [ ] No credentials, tokens, private URLs, or personal data are included.
- [ ] The repository README links to the curriculum and reproduction steps.
- [ ] The final AWS environment has been destroyed or explicitly retained with a cost owner.
