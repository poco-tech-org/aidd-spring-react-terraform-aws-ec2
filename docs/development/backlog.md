# Implementation backlog

The backlog follows the order in `curriculum.yaml`.

| Area | Done when |
|---|---|
| Backend | API, validation, persistence, errors, and tests are present |
| Frontend | Main CRUD flow has loading and error states |
| Authentication | Cognito login and JWT validation work together |
| Infrastructure | Terraform creates the intended resources |
| Deployment | A new EC2 instance starts the same application artifact |
| Availability | ALB, Auto Scaling, and RDS Multi-AZ are verified |

Turn each item into a small task with an observable verification result before asking Codex to implement it.
